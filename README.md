# Automotive Security

This repository contains projects related to automotive security.

## Local Development Setup

This section describes how to clone the repository and prepare the local Python
environment for development and testing.

The instructions below were verified on:

- Windows
- PowerShell
- Python 3.12.4
- Python virtual environment (`.venv`)
- pytest 9.1.1

The setup is designed so that the Python environment remains local to the
developer's machine. The `.venv` directory must not be committed to Git.

---

## 1. Clone the repository

Open PowerShell and navigate to the directory where you want to store the
project.

```powershell
git clone https://github.com/Zukhra-Abdulaeva/Automotive-Security.git
